# Ars Scry Anywhere

Small [Ars Nouveau](https://modrinth.com/mod/ars-nouveau) addon that lets the **Enchanter's Eye** cast through a **Scry Crystal in any dimension**.

The Enchanter's Eye already remembers which dimension its Scry Crystal is in, but Ars Nouveau only looks for the crystal in the dimension you're standing in. With this mod, an Eye bound to a crystal in the Overworld works from the Nether, the End or any other dimension. For example, you can open a Storage Lectern at your base with an Interact spell.

- Works with a bound Eye and with a Scryer's Scroll held in the offhand.
- The crystal's chunk still has to be loaded, same as in vanilla Ars Nouveau.
- Spells resolve in the crystal's dimension. A Blink cast through the Eye teleports you to the crystal's dimension.

## Install
- **Singleplayer:** install it on your client.
- **Multiplayer:** install it on the server. Players don't need it, but it doesn't hurt.
